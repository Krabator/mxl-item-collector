# Explications des compétences : suivi de ce qui n'est pas encore affiché correctement

Relevé du 01/10/2026 sur les **417 compétences** données par les objets du catalogue (outil :
`python mxl_skill_report.py [personnage.d2s]`, qui recalcule ces chiffres). Une ligne non calculée est signalée en gris
dans l'application (« … varies by character », « … not calculated » ou une note sous « Current Skill Level »).

| Référence | Lignes non calculées |
|---|---|
| Sans personnage (écran Library) | 742 |
| Avec Nekratall (coffre) | **0** (379 avant le temps de recharge, 308 avant les invocations, 192 avant les formats relus dans le jeu, 15 avant les taux de conversion, 6 avant les projectiles) |

Avec un personnage, ce qui reste ne dépend plus du personnage : ce sont des valeurs que le jeu ne connaît qu'en cours de
partie, ou un mécanisme pas encore décodé.

## 1. Ce qui reste avec un personnage

Plus rien : toutes les lignes du catalogue sont calculées avec Nekratall (voir « Fait » et « Affichage à vérifier »).

## 2. Compétences sans fiche dans le jeu

20 compétences citées par 54 objets (Thunder Wave, Arrow, Javelin, Fire Splash, Celerity…) n'ont ni texte ni lignes
dans le jeu (relevé du 02/10, toutes données par des chances de lancer). **Toutes sont décrites depuis le 02/10** à
partir de leurs données et du code du jeu (voir « Fait ») ; une compétence sans fiche hors de ces mécanismes vérifiés
garde la part des dégâts de l'arme et la note grise (ex. Stampede Nova). L'application montre la part des dégâts de l'arme quand elle n'est pas nulle (6 compétences : Thunder Wave
112 %, Athulua's Wrath 60 %, Thunder Hammer 60 %…) et la note grise « (no description in game data) ». Pour les autres,
décrire l'effet demanderait de lire les données de leur projectile ou de leur état (chantier plus long).

## 3. Sans personnage de référence (écran Library)

Les 742 lignes comprennent, en plus de ce qui précède, tout ce qui dépend du personnage : dégâts élémentaires
(242 lignes : synergies, Énergie, Spell Focus…) et physiques (36), stats (130), temps de recharge (95, réduction des
objets), points investis (`blvl`, `bl12`… : 84), autres compétences (51), améliorations des objets (`syn1`… : 38),
invocations (`mnhp`, `mnar` : 36), niveau du personnage (17). C'est voulu : ces valeurs n'ont pas de sens sans
personnage, d'où « varies by character ».

## 4. Affichage à vérifier

- **Couleur qui continue d'une ligne à l'autre** : d'après D2Win.dll, un code couleur d'une ligne dsc2 continue sur les
  lignes dsc2 au-dessus (ex. Spellbind : « Cooldown: 10 seconds » en orange après « Petrify ») ; règle lue dans le code,
  pas encore vue sur une capture. Le retour au blanc sur « Current Skill Level » est déduit de la capture d'Ignis Fatuus.
- **Lignes de synergie** (lignes 11 à 17 de la fiche) : pas affichées, comme le jeu pour une compétence donnée par un
  objet (captures d'Ignis Fatuus et de Flamefront).

## Prochain chantier : dégâts d'arme du personnage (plan)

But : remplacer « x% Weapon Damage » par « Damage: x-y » dans les explications. Source à vérifier dans le code de la
2.14.6 (ne pas la croire sur parole) : guide de Thraxis, « Introduction to Mechanics Guide »
(https://forum.median-xl.com/viewtopic.php?t=22672, Median XL Σ 2.14, incomplet). Ordre de calcul selon le guide :

1. bonus éthéré (+25 % des dégâts de base de l'arme ; déjà dans l'application : ×1,25 arrondi vers le bas) ;
2. % de dégâts améliorés (ED) ;
3. dégâts plats ;
4. % de dégâts physiques : EWD des objets, bonus de compétences et d'auras, bonus d'attributs (Force / Dextérité) ;
5. coup mortel (Deadly Strike : ×2, avant la conversion) ;
6. conversion en élémentaire ;
7. dégâts élémentaires plats (arme, équipement, compétences) ; selon le guide, le % de dégâts des sorts ne les
   augmente que sur une vraie attaque de mêlée ;
8. % de part d'arme de la compétence (WDM), appliqué en dernier.

Déjà lu dans Median XL (2.14.5, logique revérifiée en 2.14.6, D2Sigma.dll 0x1008a706 en 2.14.6) : la part d'arme
multiplie les dégâts min / max du personnage (stats 21 / 22, étapes 1 à 4 ?) ; dégâts élémentaires (stats 329-332,
357, lus par une fonction de Median XL) multipliés par un coefficient tiré de la part d'arme (fonction non décodée :
règle « mêlée seulement » du guide ?) ; % de dégâts (stat 25) et bonus contre démons / morts-vivants ; doublement
sous condition (coup mortel, étape 5). À établir : ce que contiennent les stats 21 / 22 du personnage (ED, Force /
Dextérité compris ?), la fonction des dégâts élémentaires et son coefficient ; contrôle : capture de la ligne
« Damage » de la feuille de personnage de Nekratall.

Écarts du guide avec la 2.14.6 : bonus d'Énergie aux sorts (guide : 260 × (Énergie + 10) / (250 + Énergie) +
min(Énergie × facteur / 15000, 200) ; jeu : 50 + 130 × (Énergie + 20) / (500 + Énergie) + min(Spell Focus / 10,
100)) ; « part d'arme des procs en général 50 % » (jeu : 37 à 199 % selon la compétence).
